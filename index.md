# Politique de confidentialité de SavedTempo

Dernière mise à jour : 19 août 2026

SavedTempo est une application de métronome et d’entraînement musical développée par JB.

Cette politique de confidentialité explique quelles données peuvent être utilisées par l’application, dans quel but, et comment elles sont traitées.

## Données stockées localement

SavedTempo enregistre localement sur l’appareil les données nécessaires à son fonctionnement, notamment :

- morceaux, exercices et entraînements enregistrés ;
- sections et paramètres de métronome associés ;
- setlists ;
- préférences de l’application ;
- partitions ou images scannées/importées par l’utilisateur.

Ces données restent stockées sur l’appareil, sauf lorsqu’une fonctionnalité de partage ou de publication est utilisée volontairement par l’utilisateur.

## Caméra

SavedTempo peut utiliser la caméra de l’appareil pour :

- activer le flash sur les temps du métronome ;
- scanner une partition ou une feuille d’exercice.

Les images scannées sont enregistrées localement sur l’appareil.

SavedTempo n’envoie pas automatiquement les images scannées vers un serveur distant.

## Images et fichiers

L’utilisateur peut choisir une image ou un fichier depuis le stockage de son appareil afin de :

- joindre une partition à une section ;
- importer un fichier SavedTempo ;
- exporter ou partager ses données.

SavedTempo n’accède qu’aux fichiers explicitement sélectionnés par l’utilisateur via les mécanismes Android prévus à cet effet.

## Import et export

SavedTempo permet d’exporter des données au format `.savedtempo`.

Selon le contenu exporté, ce fichier peut inclure :

- les données d’un morceau, exercice ou entraînement ;
- les paramètres associés ;
- une partition ou image liée à une section.

L’export ou le partage est toujours déclenché volontairement par l’utilisateur.

## Fonction Communauté et Supabase

SavedTempo peut utiliser Supabase pour certaines fonctionnalités liées à la Communauté.

Dans ce cadre :

- une authentification technique anonyme peut être créée ;
- des contenus publiés volontairement peuvent être envoyés vers les services Supabase ;
- ces données sont utilisées uniquement pour permettre les fonctionnalités de publication, consultation ou import liées à la Communauté.

SavedTempo ne vend pas les données personnelles de ses utilisateurs.

## Données personnelles

SavedTempo ne demande pas à l’utilisateur de créer un compte personnel pour utiliser les principales fonctions de l’application.

L’application ne demande pas directement :

- nom ;
- adresse postale ;
- numéro de téléphone ;
- date de naissance.

Certaines données techniques peuvent toutefois être traitées par les services utilisés par l’application, notamment Google Play et Supabase, conformément à leurs propres politiques de confidentialité.

## Partage des données

SavedTempo ne partage pas automatiquement les données locales de l’utilisateur avec des tiers.

Un partage peut avoir lieu uniquement lorsque l’utilisateur utilise volontairement une fonctionnalité telle que :

- partager un fichier `.savedtempo` ;
- publier un contenu dans la Communauté ;
- choisir une application externe via le menu de partage Android.

## Conservation et suppression

Les données locales sont conservées sur l’appareil jusqu’à ce que l’utilisateur :

- les supprime dans SavedTempo ;
- désinstalle l’application ;
- efface les données de l’application via Android.

Les partitions ou images associées peuvent également être supprimées directement depuis SavedTempo.

Les contenus publiés dans la Communauté peuvent être soumis aux mécanismes de conservation du service distant utilisé.

## Sécurité

SavedTempo utilise les mécanismes standards d’Android pour le stockage local, la sélection de fichiers et l’accès aux fonctions matérielles.

Les données privées de l’application sont stockées dans l’espace interne de l’application lorsqu’il est approprié de le faire.

## Enfants

SavedTempo n’est pas spécifiquement destiné aux enfants et ne collecte pas volontairement de données personnelles auprès d’enfants.

## Modifications de cette politique

Cette politique de confidentialité peut être mise à jour afin de refléter des modifications de l’application ou de ses fonctionnalités.

La date de dernière mise à jour est indiquée en haut de cette page.
